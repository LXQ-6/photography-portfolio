00连接 GitHub

如何获取令牌？（首次使用需约 1 分钟）
  1. 打开 github.com → 右上角头像 → Settings → 左侧最底部 Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Token name 随意；Repository access 选 Only select repositories → 勾选 photography-portfolio
  4. Permissions → Repository permissions → Contents 设为 Read and write
  5. 生成后复制令牌（ghp_ 开头），粘贴到上方输入框点"连接"。令牌只存在你的浏览器本地，不会上传到任何地方
